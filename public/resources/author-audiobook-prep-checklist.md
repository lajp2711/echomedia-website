# Author Audiobook Prep Checklist

Use this checklist before sending a manuscript into AI narration, ElevenReader, or a professional audiobook workflow.

## 1. Manuscript Structure

- [ ] Confirm title, subtitle, author name, and series name.
- [ ] Confirm chapter order.
- [ ] Remove duplicate chapter files or old drafts.
- [ ] Decide which front matter should be read aloud.
- [ ] Decide which acknowledgments, manifest sections, notes, or appendices should be excluded from narration.

## 2. Formatting Guidance

- [ ] Bold the book title.
- [ ] Bold every chapter heading.
- [ ] Use consistent heading patterns for preface, prologue, chapters, epilogue, and appendices.
- [ ] Remove broken page numbers, headers, footers, and manuscript-only notes.
- [ ] Make scene breaks explicit with a consistent marker.

## 3. Audio Readability

- [ ] Read difficult paragraphs aloud or run a sample narration pass.
- [ ] Break up sentences that look fine on the page but tangle in the ear.
- [ ] Flag intentionally repeated phrases so they are not mistaken for copy errors.
- [ ] Add pronunciation notes for names, invented terms, places, and acronyms.
- [ ] Check dialogue tags and speaker clarity in long exchanges.

## 4. Test Chapter Process

- [ ] Select one early chapter and one emotionally intense chapter for test narration.
- [ ] Generate audio samples with the intended voice settings.
- [ ] Listen for pacing, warmth, tension, clarity, and fatigue.
- [ ] Adjust manuscript formatting before producing the full book.
- [ ] Save voice settings and notes for repeatability across sequels.

## 5. Listening QA

- [ ] Listen chapter by chapter.
- [ ] Track corrections in a shared notes document.
- [ ] Mark timing or chapter location for each issue.
- [ ] Separate manuscript fixes from narration settings fixes.
- [ ] Re-run only corrected sections when possible.

## 6. Publishing Prep

- [ ] Export a clean narration-ready manuscript.
- [ ] Keep a separate print/KDP manuscript if formatting needs differ.
- [ ] Prepare audiobook description and sample text.
- [ ] Prepare disclosure language for AI-assisted narration where needed.
- [ ] Track release decisions for free, premium, or series-bundle strategy.
