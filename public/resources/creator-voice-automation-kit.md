# Creator Voice Automation Kit

Use this kit to design a repeatable, consent-first AI voice workflow for creator content.

## 1. Creator Voice Goals

- [ ] Define the primary voice use case.
- [ ] Decide whether the workflow supports short-form video, long-form narration, courses, lead magnets, podcasts, or multilingual content.
- [ ] Define the audience and tone.
- [ ] Decide what should never be generated in the creator's voice.

## 2. Consent and Rights

- [ ] Confirm the voice owner has explicitly approved the workflow.
- [ ] Document allowed platforms and use cases.
- [ ] Document prohibited use cases.
- [ ] Document who can generate, approve, publish, and archive voice content.
- [ ] Store consent notes with the project records.

## 3. Content System

- [ ] Create reusable script templates.
- [ ] Create hooks for short-form clips.
- [ ] Create calls to action for services, lead magnets, or community offers.
- [ ] Create voiceover notes for pacing, emotion, pronunciation, and tone.
- [ ] Create a review checklist before publication.

## 4. Production Workflow

- [ ] Draft script.
- [ ] Generate test audio.
- [ ] Review for tone and accuracy.
- [ ] Revise script or voice settings.
- [ ] Approve final audio.
- [ ] Publish and track performance.

## 5. Weekly Content Plan

| Day | Asset | Voice Use | CTA | Review Owner | Status |
| --- | --- | --- | --- | --- | --- |
| Monday | Short-form clip | Hook narration | Follow / subscribe | Creator | Draft |
| Wednesday | Educational post | Explainer voiceover | Download resource | Creator | Draft |
| Friday | Offer clip | Promo voiceover | Book consult | Creator | Draft |
