## Voice Cloning Consent Checklist

Core rule:

> Only clone or use a voice if you own it or have explicit permission from the person whose voice is being used.

Consent should define:

- Approved use cases
- Approved platforms
- Commercial use
- Political use
- Sensitive content permissions
- Review requirements
- Revocation process
- Expiration date, if any

Red flag uses:

- Fake endorsements
- Impersonation without disclosure
- Financial scams
- Political deception
- Harassment
- Deepfake-style manipulation without consent
- Adult/sensitive content without explicit approval
- Any use outside approved scope
